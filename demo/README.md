# Demo assets

- **semantic_guardian_final.mp4** — the full ~2 min narrated demo (the submission video).
- **architecture.png** — two-stage agent architecture diagram (used in the top-level README).
- **hero.mp4 / terminal_live.mp4 / datahub_assertions.mp4** — real footage segments the demo is built from

- **hero.html** — the animated hero, rendered and screen-captured.
- **audio/** — voiceover track per segment.

The video is built by `scripts/assemble_final.py`.
